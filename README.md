# OwnNet — Tu red, donde estés

Página de presentación de un proyecto académico de conectividad comunitaria.

## Publicar con GitHub Pages
1. Crea un repositorio público llamado `ownnet`.
2. Sube `index.html`, `ownnet.mp4` y `portada.png` a la raíz del repositorio.
3. Abre Settings > Pages > Build and deployment > Deploy from a branch.
4. Selecciona `main` y `/ (root)` y guarda.
5. Abre `https://TU-USUARIO.github.io/ownnet/` cuando termine la publicación.

El video se reproduce en la misma página sin YouTube. La reproducción comienza al pulsar Play.
